
# College Assignment Tracker

A college assignment tracker built with Python and Drafter.

## Live Website
https://isickler.github.io/college-assignment-tracker/

## Features
- Add assignments with names, classes, due dates, and priorities
- Mark assignments as completed
- Filter assignments by class
- Filter unfinished assignments by priority
- View assignment progress and overdue assignments
